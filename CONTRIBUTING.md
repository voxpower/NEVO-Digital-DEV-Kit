# Contributing to NEVO_Digital_DevKit

Thank you for considering contributing to the NEVO_Digital_DevKit project! We appreciate your help in making this project better.

## How to Contribute

There are several ways you can contribute:

*   **Report Bugs:** If you find a bug, please open an issue on the GitHub repository. Provide a clear and concise description of the bug, steps to reproduce it, and your environment details.
*   **Suggest Features:** Have an idea for a new feature or improvement? Open an issue to discuss it.
*   **Submit Code Changes:**
    1.  **Fork the repository** on GitHub.
    2.  **Clone your forked repository** to your local machine.
    3.  **Create a new branch** for your changes (e.g., `feature/my-new-feature` or `bugfix/fix-some-bug`).
        ```bash
        git checkout -b feature/your-feature-name
        ```
    4.  **Make your changes.** Ensure your code adheres to the existing coding style. We use `clang-format` for code formatting.
    5.  **Write clear and concise commit messages.**
    6.  **Push your branch** to your forked repository.
    7.  **Open a Pull Request (PR)** to the `main` branch of the original NEVO_Digital_DevKit repository.
        *   Provide a clear title and description for your PR, explaining the purpose of your changes.
        *   Reference any related issues (e.g., "Fixes #123" or "Implements #456").

## Code Style

Please adhere to the existing code style. You can use `clang-format` to format your C/C++ code.

## Pull Request Guidelines

*   Keep your pull requests focused on a single feature or bug fix.
*   Ensure all existing tests pass.
*   If you've added new functionality, please consider adding unit tests.
*   Be responsive to feedback on your pull request.

## Developer Certificate of Origin (DCO)

By contributing to this project, you agree to the Developer Certificate of Origin (DCO). This is a simple declaration that you wrote the contribution or have the right to submit it. The text of the DCO can be found at [https://developercertificate.org/](https://developercertificate.org/). You signify your agreement to the DCO by adding a `Signed-off-by:` line to your commit messages.

Example:
```
git commit -s -m "Your commit message"
```
The `-s` flag will automatically add the `Signed-off-by:` line.

Thank you for your contributions!
